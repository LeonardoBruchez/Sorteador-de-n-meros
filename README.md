# Sorteador de Números

## 📖 Sobre o Projeto

Este é um projeto simples de um sorteador de números online e gratuito, desenvolvido com o objetivo principal de aprimorar e praticar habilidades em JavaScript, além de revisitar conceitos de HTML5 e CSS3. A aplicação permite ao usuário definir um intervalo numérico e a quantidade de números a serem sorteados, exibindo o resultado de forma clara e rápida.

Este projeto foi criado puramente para fins de aprendizado e portfólio.

## ✨ Funcionalidades

*   **Definir Quantidade:** Escolha quantos números você deseja sortear.
*   **Intervalo Personalizado:** Defina o valor mínimo e máximo para o sorteio.
*   **Não Repetir Números:** Opção para garantir que os números sorteados sejam únicos.
*   **Responsividade:** Interface adaptada para funcionar tanto em dispositivos móveis quanto em desktops.
*   **Geração Aleatória:** Utiliza algoritmos de JavaScript para garantir a aleatoriedade dos números.

## 💻 Tecnologias Utilizadas

*   **HTML5:** Estrutura semântica da página.
*   **CSS3:** Estilização e design responsivo, utilizando Flexbox e Grid Layout.
*   **JavaScript (ES6+):** Lógica do sorteador, manipulação do DOM e interatividade.

## 🚀 Como Executar

1.  Clone o repositório para sua máquina local.
2.  Navegue até o diretório do projeto.
3.  Abra o arquivo `index.html` em seu navegador de preferência.

Pronto! Agora você pode usar o sorteador.

## 🎯 Objetivos de Aprendizado

O foco principal deste projeto foi aprofundar os conhecimentos em JavaScript, abordando os seguintes tópicos:

*   Manipulação de elementos do DOM (Document Object Model).
*   Captura e tratamento de eventos do usuário (cliques, inputs).
*   Implementação da lógica para geração de números aleatórios com e sem repetição.
*   Uso de funções, condicionais e laços de repetição.
*   Prática de boas práticas de organização de código.
*   Revisão de conceitos de HTML semântico e CSS para criação de layouts responsivos.
